# e-plantShopping

e-plantShopping is a React-based web application that allows users to browse and shop for a variety of plants online. The application provides a clean and user-friendly shopping experience with features such as product listing, shopping cart management, and real-time updates using Redux.

## Project Overview

The e-plantShopping application simulates an online plant nursery where users can:
- View different categories of plants
- Add plants to a shopping cart
- Increase or decrease plant quantities in the cart
- Remove plants from the cart
- View the total cost of items in the cart
- Continue shopping or proceed to checkout (future enhancement)

## Technologies Used

- React
- Redux Toolkit
- JavaScript (ES6)
- HTML5
- CSS3

## Features

- Product listing with plant details (name, image, description, and cost)
- Add to Cart functionality
- Shopping cart with quantity management
- Real-time cart updates using Redux state management
- Responsive and user-friendly UI

## Future Enhancements

- Checkout and payment integration
- User authentication
- Backend integration for persistent data storage
